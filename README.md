# 🎵 NXT-Music 🎧  
A Full-Stack Music Streaming App built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js), featuring modern spatial audio, song uploads, album management, and high-fidelity real-time playback.

---

## 🚀 Features

- 🎼 **Upload Songs** with metadata and high-resolution cover art
- 💿 **Create & Manage Albums** with custom artwork and playlists
- 📂 **Store Media Files** with Cloudinary CDN
- 🔊 **Next-Gen Spatial Music Player** with lossless playback, audio visualizer, seek, and volume control
- 🗃️ **Curated Charts & Vault** - save favorite tracks and browse curated masters
- ⚙️ **RESTful APIs** with Express and MongoDB
- 🌐 **Modern Glassmorphic Frontend** in React + Tailwind CSS
- 🛠️ **Dedicated Admin Dashboard** for music and album operations

---

## 🛠️ Tech Stack

### Frontend & Admin:
- React.js 19
- Tailwind CSS
- Axios
- React Context API (global audio player state)
- Vite

### Backend:
- Node.js
- Express.js
- MongoDB + Mongoose
- Cloudinary (media upload & CDN streaming)

## ⚙️ Setup Instructions

### 🔐 Prerequisites:
- Node.js (v20.x or v22.x LTS) & npm
- MongoDB Atlas or local MongoDB
- Cloudinary account (for audio/image storage)

### 🔄 Clone the Repository

```bash
git clone https://github.com/koushik369mondal/NXT-Music.git
cd NXT-Music
```

### 📦 Installation

```bash
# Install backend dependencies
cd backend && npm install

# Install frontend dependencies
cd ../frontend && npm install

# Install admin dependencies
cd ../admin && npm install
```

### 🚀 Running Locally

```bash
# Start backend server (port 4000)
cd backend && npm run dev

# Start frontend application (port 5173)
cd ../frontend && npm run dev

# Start admin panel (port 5174)
cd ../admin && npm run dev
```
